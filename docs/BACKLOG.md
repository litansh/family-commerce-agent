Whatever ranks `buildChoice`'s candidates for a query with no meaningful tokens needs a floor: no candidate, not a guessed one, when nothing in the query matches anything in the name. Emoji-only and empty queries correctly resolve to nothing today; a bare number does not. *api-fixer*
